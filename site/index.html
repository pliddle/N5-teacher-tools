Good to know

  • Everything follows the N5 course specification and uses SQA-style reference language. The questions are our own, written in the style of the exam.
  • The starter, stepper and SQL tools run entirely in your browser. The live quiz keeps each game in memory only while it runs and saves nothing about pupils afterwards (only daily visit totals are counted): no accounts, no cookies, and pupils play under random names. If you ask for names for your results spreadsheet, they appear only in your download, never on the board.
  • Works on a projector or interactive board: every tool has bigger and smaller text (+ −) and full screen (F).
  • The approach owes a lot to Scottish computing education research, including the work behind the SQA reference language and the PLAN C programme for teachers: see Built with science.
  • Pupils who want to keep going can revise on national5computing.co.uk.
